Python 快速上手新库的方法

导入新库，按顺序敲下面 4 行代码，快速了解这下面有啥东西

import 刚装的库名

# 1. 看白名单（如果有），如果库作者比较规范，会在库的 __init__.py 里定义 __all__ 列表。这相当于作者亲口告诉你我就推荐你用这几个
print("推荐使用:", getattr(刚装的库名, '__all__', '未定义'))

# 2. 看公开类有哪些，打印不带下划线的公开名称
import inspect
类列表 = [m[0] for m in inspect.getmembers(刚装的库名, inspect.isclass) if not m[0].startswith('_')]
print("包含的类:", 类列表)

# 3. 看公开函数有哪些
函数列表 = [m[0] for m in inspect.getmembers(刚装的库名, inspect.isfunction) if not m[0].startswith('_')]
print("包含的函数:", 函数列表)

# 4. （可选）如果看到有个类叫 Client，直接 help 它
# help(刚装的库名.Client)

那假如一个库返回了一个 pojo，我如何知道这个结构里面的字段都是啥含义呢

1，dir(obj)：这是总目录。它会列出该对象所有的属性和方法名（包括带下划线的魔法方法）。只看不带_的，那就是你能用的公开接口 2，help(obj)：这是使用说明书。会打印出该对象的官方文档字符串，里面通常写着参数、返回值和例子 3，type(obj)：先看看它是个啥（是list、dict，还是某个类class？）。有时候你以为是字典，其实是个对象 4，vars(obj)：看 response 里存了啥具体数据

# 假设你调用了某个库，拿到了一个对象 response
print(type(response))        # 先看类型，比如 <class 'requests.models.Response'>
print(dir(response))         # 看有哪些方法，你会看到 .json(), .text, .status_code 等
help(response.json)          # 专门看 .json() 这个方法是干啥的
from pprint import pprint
pprint(vars(response))        # 看到 response 里存了啥具体数据，你会看到 {'_content': b'...', 'status_code': 200, 'headers': {...}}
