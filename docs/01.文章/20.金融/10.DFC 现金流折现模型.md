## 估值锚定方法
**内在价值是唯一的锚**

巴菲特的估值哲学浓缩为四个关键词："能力圈"、"逆向投资"、"安全边际"、"长期持有"。其中估值层面的核心工具是**自由现金流折现模型（DCF）——"公司现在的内在价值 = 未来每年能自由支配的现金流，按一定折现率折算成今天的总和"**。它通过预测企业未来产生的自由现金流，并以适当的折现率将其折现回现值，得出企业的内在价值。巴菲特和芒格都认可 DCF 的逻辑，认为一家公司的内在价值等于其未来生命周期内所能产生的自由现金流的折现值。然而，DCF 模型的复杂性和对未来的高度不确定性，使得普通投资者难以准确应用

在实际应用中，巴菲特自己也坦言不会拿着计算器精确计算内在价值，他更强调的是"一眼就能看出来很值"的模糊正确。芒格的投资评估过程也是如此：最重要的观念是把股票当成企业的所有权，根据竞争优势来判断企业的持有价值，如果企业未来的贴现现金流比现在购买的股票价格要高，那么这个企业就具有投资价值

DCF 的运用更像是一种严谨的思维框架，用来逼迫你透彻理解一家公司的生意模式、盈利驱动和风险因子，**而不是一套可以机械代入的数字游戏**，不是计算、不是计算、不是计算
## 三区间估值框架
有些人将企业的估值状态分为三个区间，即三区间估值框架：

1，低估区间：股价低于内在价值，此时买入有安全边际保护。巴菲特追求的是"用40美分购买价值1美元的股票"

2，合理区间：股价大致匹配内在价值，虽然没有安全边际，但持有依然可以享受企业成长带来的回报。此时核心关注的是分红收益和企业内在价值的增长速率

3，高估区间：股价超过内在价值，安全边际消失，追高风险显著加大。如果价格"远高于"价值，且找不到合理的未来增长来支撑当前价格，才考虑卖出

根据巴芒体系的"凯利公式导向"和"集中投资原则"，仓位配置取决于确定性和赔率。芒格认为当一只股票的确定性足够高时，仓位可以适度集中，分散投资反而会稀释优势。因此我的投资策略为满仓单吊，在保证仓位设计如下：

1，基本仓（核心底仓），总资产的 66%，除非基本面逻辑彻底破坏或出现不可逆的恶化，否则永不卖出，	低估区建仓完毕，合理区和高估区均持股不动
2，波动仓（机动仓位），总资产的 33%，仅在低估区间分批买入，高估区间分批卖出，合理区呆坐不动

始终以显著低于内在价值的价格买入证券，为失误和不利变化提供缓冲。市场先生短期是情绪化的躁郁症患者，聪明的投资者应利用其恐慌和贪婪逆向操作，而非被其左右，是聪明的投资者中的重要投资哲学，那如何判断目前的股价是否处于低估区间、是否处于高估区间呢、具体怎么估呢？

将价格划分为三个区间事实上最难的部分是找到正确的区间值，区间值则看你对企业的理解程度，普通人很难算准，就算接下来我将介绍 DCF 的大致流程，这是为了帮助我们算出一个估值，这个估值很可能不准，但是没关系，因为我们的目标是根据区间，而不是具体的数值

## DCF 估值流程
估值方式已经说过，是未来每年能自由支配的现金流，按一定折现率折算成今天的总和。大致流程：做 3–5 年的粗略现金流预测 + 简化折现率 + 永续增长 0–2%，得出一个价值区间，再结合 PE/PB 等指标一起判断

先解释一下为什么要呢折现？假设两个选择，一是今天给你100万，二是10年后给你100万，绝大多数人会选 A。因为今天的钱可以拿去投资、消费，而10年后的100万还要面对通货膨胀和不确定性。这就是货币的时间价值，DCF 的本质就是对一家公司未来每年产生的现金流，逐一折现到今天的价值，然后加总。折现率（r）越高，未来现金流缩水越多，公司估值就越低。这也符合直觉：风险越大的公司，你要求的回报越高，它在你眼里就越不值钱

```
V = ∑ [CFt / (1 + r)^t]
```
符号	|含义
-|-
V|	资产今天的价值（估值结果）
CFt|	第 t 年公司能产生的自由现金流
r|	折现率（把未来钱打折的比率）
t	|第几年
∑ | 这些年的总和

简单说就是把未来每一年的自由现金流，除以(1+折现率)的 t 次方，再把所有年份的结果加起来，里面的关键参数需要额外讲解

### 自由现金流
DCF 用的不是净利润，而是自由现金流（FCF）。净利润是会计上的纸面利润，可能包含没收到钱的收入。自由现金流是公司维持正常运营和必要投资后，真正剩下、可以自由支配的现金。比如公司今年赚了100亿，但为了维持生意需要花30亿买设备、建厂房，那真正的自由现金流就是70亿，而不是100亿

DCF 之所以看重自由现金流，是因为现金更难被会计手段粉饰，更能反映公司真正赚到手的钱

**口径警示，新手第一大坑**：上式中的 FCF 取 **FCFF（企业自由现金流）** 时，`r` 必须用 **WACC**，算出的结果是**企业价值（EV）**，必须**再减净债务**才是股权价值；若取 FCFE（股东自由现金流），`r` 用 Re、结果直接是股权价值。两套口径不能混搭。FCFF 和 FCFE 到底是个啥？

- FCFF（企业自由现金流）：这是公司还完所有经营成本、交完税之后，在给债权人（银行）还本付息之前，所拥有的全部现金流。这笔钱是属于全公司的（股东+债主）
- FCFE（股东自由现金流）：这是公司还完了所有银行利息和本金之后，最终只剩下股东能分到的那笔钱

### 折现率
折现率可以理解为你对这笔未来现金流要求的最低回报率。它通常用加权平均资本成本（WACC） 来表示，WACC 的计算公式是：
```
WACC = (E/V) × Re + (D/V) × Rd × (1 - Tc)
```
符号|	含义
-|-
Re|	股东要求的回报率（股本成本），对股东来说，这是他们放弃其他投资机会（比如存银行或买其他股票）所要承受的机会成本，这是一个目标，是主观的、有野心的，是估计出来的
Rd|	债权人的利息成本（债务成本），可以在可转债的利率合同中找到，或者查看公司财务报表附注里的利息支出和带息债务总额，自己估算一个平均利率
Tc|	公司税率，中国境内一般企业法定税率是25%。但实际中，高新技术企业可能是15%，或有其他税收优惠，可以去去公司财务报表附注的所得税费用部分查找
E/V|	股权占总资本的比例，E 是公司股权的市场价值（总市值），D 是公司债务的市场价值，EV 和 DV 相加是百分之百
D/V	| 债务占总资本的比例。理想情况是用债务的市场价值（比如债券的市场价格），但大多数公司债务（如银行贷款）没有公开市场交易。因此，实践中常用债务账面价值近似代替（注意不是公司的账面价值，而是有息负债的账面价值）

注意，Re（股本成本）绝对不能直接换成分红率，如果你把它换成分红率，算出来的估值会严重偏高，导致你做出错误的投资决策。绝大多数公司还在成长。比如一家优秀的公司，市场预期它未来每年利润能增长 8%，同时它现在股息率是 2%。那么，投资者要求的回报率 Re 就是 2% + 8% = 10%。如果你在 DCF 公式里把 Re 直接填成 2%（股息率），而放弃了那 8% 的成长预期，你相当于用极低的折现率去折现未来的钱。折现率越低，现值越高。 这样算出来，哪怕一家很平庸的公司，你也会把它估值成万亿巨头

折现率越高，未来现金流的现值就越低。换句话说，风险越高的公司，折现率越高，今天的估值就越低

实际操作中，**无风险收益率通常参考10年期国债收益率（目前中国约在1.6794%上下）**，这个可以随便搜到
### 终值（Terminal Value）
公司不可能只存活5年或10年，所以 DCF 通常分两部分：

- 预测期：未来5-10年，逐年的自由现金流
- 永续期：预测期之后，公司永远经营下去的价值（终值）

终值往往占 DCF 估值的60%-80%，而它又极度依赖永续增长率这个假设——稍微改一点点，结果天差地别

DCF 的价值不在于给出一个精确数字，而在于把模糊的贵不贵转化为一个具体的问题：”公司能不能做到 X% 的增长？” 这个问题你可以用行业研究、竞争分析和公司基本面来回答。而现实中还有其他风险：

- 行业格局可能被颠覆（诺基亚、柯达）
- 管理层可能犯错
- 宏观环境可能剧变
- 技术进步可能改变一切
### 函数代码
```py
# -*- coding: utf-8 -*-
"""估值引擎：FCF / WACC / 三年显性期 DCF / 敏感性分析 / 反向 DCF。

本文件是纯函数模块，不碰网络——所有输入来自 data.py 拉取并核对过的数据。
每个函数的 docstring 都回答「这一步在算什么、为什么这么算」，
与 README.md 的教程章节一一对应。

核心口径（务必先读）：
    本项目采用 **FCFF（企业自由现金流）口径**：
        FCF = 经营活动现金流净额 - 资本支出(Capex)
        企业价值 EV = Σ FCFFt/(1+WACC)^t + 终值折现
        股权价值 = EV - 净债务 - 少数股东权益   # 净债务 = 有息负债 - 货币资金
        每股内在价值 = 股权价值 / 总股本
    折现率必须用 WACC（债权人和股东要求的加权回报），因为 FCFF 是
    「属于全体资本提供者」的现金流。若改用 FCFE（股东自由现金流），
    则折现率用 Re、且不扣净债务——两种口径不能混搭，这是新手第一大坑。
"""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np
import pandas as pd

from data import StockData

# 有息负债科目：只有这些科目是「借来的钱」，要付利息，参与 WACC 的 D 项。
# 应付账款/合同负债等经营性负债不算——它们是无息的商业信用。
INTEREST_DEBT_ITEMS = [
    "短期借款",
    "应付短期债券",
    "一年内到期的非流动负债",
    "长期借款",
    "应付债券",
    "租赁负债",
]


# ---------------------------------------------------------------------------
# 第一步：历史自由现金流
# ---------------------------------------------------------------------------

def fcf_history(stock: StockData, years: int = 10) -> pd.DataFrame:
    """整理过去 N 年的年度 FCF 及其上下文，返回按年份升序的 DataFrame。

    FCF = 经营活动现金流净额 - 购建固定资产等支付的现金(Capex)

    为什么不直接用净利润：净利润是权责发生制的「纸面利润」，可能包含
    没收到钱的收入；FCF 才是维持生意后真正剩下的现金，更难被粉饰。
    表里的「FCF/净利润」列就是用来检验利润含金量的——长期低于 70%
    说明利润都在应收款和存货里，这种公司的 DCF 要大打折扣。
    """
    rows = []
    cols = ["年份", "营业收入(亿)", "归母净利润(亿)", "经营现金流(亿)",
            "资本支出(亿)", "FCF(亿)", "FCF/净利润"]
    ocf = stock.series("cashflow", "经营活动产生的现金流量净额")
    capex = stock.series("cashflow", "购建固定资产、无形资产和其他长期资产所支付的现金")
    revenue = stock.series("income", "营业收入")
    profit = stock.series("income", "归属于母公司所有者的净利润")
    for year in sorted(set(ocf.index) & set(capex.index)):
        if years and year < (pd.Timestamp.now().year - years):
            continue
        fcf = ocf[year] - capex[year]
        np_att = profit.get(year, np.nan)
        rows.append({
            "年份": year,
            "营业收入(亿)": revenue.get(year, np.nan) / 1e8,
            "归母净利润(亿)": np_att / 1e8,
            "经营现金流(亿)": ocf[year] / 1e8,
            "资本支出(亿)": capex[year] / 1e8,
            "FCF(亿)": fcf / 1e8,
            "FCF/净利润": fcf / np_att if np_att and np_att > 0 else np.nan,
        })
    df = pd.DataFrame(rows, columns=cols)
    return df.set_index("年份") if len(df) else df


def net_debt(stock: StockData) -> float:
    """最新一期净债务 = 有息负债合计 - 货币资金，单位元。可为负（净现金）。

    净债务为负说明公司账上现金比借款多，从 EV 换算股权价值时要「加回来」，
    所以这里不做 max(·, 0) 截断——截断会白白抹掉净现金公司的价值。
    """
    debt = sum(stock.latest("balance", item)
               for item in INTEREST_DEBT_ITEMS if item in stock.statements["balance"].index)
    cash = stock.latest("balance", "货币资金")
    return debt - cash


def minority_interest(stock: StockData) -> float:
    """最新一期少数股东权益（账面价值），单位元。无此科目时为 0。

    FCFF 是合并报表口径的现金流，属于全体资本提供者——包括子公司里
    不属于上市公司的那部分股东。从 EV 换算「归属于上市公司股东」的
    股权价值时，除了净债务还要扣掉少数股东权益，否则等于把别人那一份
    资产也算给了母公司股东。对国电电力这类少数股东权益高达数百亿
    （比归母权益还大）的公司，不扣这项会严重高估每股价值。
    """
    if "少数股东权益" not in stock.statements["balance"].index:
        return 0.0
    return stock.latest("balance", "少数股东权益")


def historical_growth(stock: StockData, item_table: str, item: str,
                      years: int = 5) -> float:
    """某科目近 N 年的复合增长率（CAGR），用于给增长假设提供锚点。

    DCF 的增长参数是最敏感的输入，不应该凭感觉填——至少要回答
    「它过去几年实际增长了多少」。CAGR 比简单平均更能抵抗单年异常。
    """
    s = stock.series(item_table, item).dropna()
    s = s[s.index >= pd.Timestamp.now().year - years - 1]
    if len(s) < 2 or s.iloc[0] <= 0:
        return float("nan")
    n = s.index[-1] - s.index[0]
    return float((s.iloc[-1] / s.iloc[0]) ** (1 / n) - 1) if n > 0 else float("nan")


# ---------------------------------------------------------------------------
# 第二步：折现率（WACC）
# ---------------------------------------------------------------------------

@dataclass
class WACCResult:
    wacc: float        # 加权平均资本成本（小数）
    cost_of_equity: float   # Re，CAPM 算出
    cost_of_debt: float     # Rd，税前
    after_tax_rd: float     # Rd × (1-Tc)
    tax_rate: float         # 实际所得税率
    equity_weight: float    # E/V
    debt_weight: float      # D/V
    market_cap: float       # E，元
    interest_debt: float    # D（有息负债账面价值），元


def wacc(stock: StockData, risk_free: float, erp: float = 0.065,
         rd_fallback: float = 0.04) -> WACCResult:
    """WACC = (E/V)×Re + (D/V)×Rd×(1-Tc)

    各项的取值逻辑（详见 README「折现率」一节）：
    - Re（股权成本）用 CAPM：Re = Rf + β × ERP。
      绝对不能用股息率充当 Re——那样等于放弃全部成长预期，
      会把平庸公司估成万亿巨头（详见 README 的专门警示）。
    - β 来自腾讯 K 线对沪深 300 的周收益率回归（data.compute_beta）。
    - ERP（股权风险溢价）取 0.065，A股惯用区间 6%-7%。
    - Rd（债务成本）优先用「财务费用/期均有息负债」估算，
      估算不出来时退回 rd_fallback（可配）。
    - Tc（实际税率）= 所得税费用 / 利润总额。高新技术企业是 15%，
      一般企业 25%，用实际数比拍法定税率更贴近。
    - E 用总市值（腾讯行情），D 用有息负债账面价值——银行贷款没有
      公开市价，账面值是公认近似。
    """
    market_cap = stock.quote["total_market_cap"]
    interest_debt = sum(stock.latest("balance", item)
                        for item in INTEREST_DEBT_ITEMS
                        if item in stock.statements["balance"].index)

    # 实际税率：用最近年报的所得税费用/利润总额
    tax_s = stock.series("income", "减：所得税费用")
    pretax_s = stock.series("income", "利润总额")
    tax_rate = 0.25
    for y in sorted(set(tax_s.index) & set(pretax_s.index), reverse=True):
        if pretax_s[y] > 0:
            tax_rate = min(max(tax_s[y] / pretax_s[y], 0.0), 0.5)
            break

    # Rd：财务费用 / 期均有息负债（资产负债表只有期初期末，取均值）。
    # 注意「财务费用」是利息支出减利息收入后的净额——现金充裕的公司
    # （利息收入高）会被低估出离谱的 Rd（伊利按此算只有 1.9%），
    # 所以设下限：Rd 至少等于 Rf + 1% 的信用利差。
    fin_exp = stock.series("income", "财务费用")
    debt_series = (pd.concat([stock.series("balance", it) for it in INTEREST_DEBT_ITEMS
                              if it in stock.statements["balance"].index], axis=1)
                   .sum(axis=1))
    rd = rd_fallback
    for y in sorted(set(fin_exp.index) & set(debt_series.index), reverse=True):
        avg_debt = (debt_series.get(y, 0) + debt_series.get(y - 1, 0)) / 2
        if avg_debt > 0 and fin_exp[y] > 0:
            rd = min(fin_exp[y] / avg_debt, 0.15)  # 防个别年份财务费用异常
            break
    rd = max(rd, risk_free + 0.01)

    cost_of_equity = risk_free + stock.beta * erp
    total_v = market_cap + interest_debt
    e_w = market_cap / total_v if total_v > 0 else 1.0
    d_w = 1.0 - e_w
    return WACCResult(
        wacc=e_w * cost_of_equity + d_w * rd * (1 - tax_rate),
        cost_of_equity=cost_of_equity,
        cost_of_debt=rd,
        after_tax_rd=rd * (1 - tax_rate),
        tax_rate=tax_rate,
        equity_weight=e_w,
        debt_weight=d_w,
        market_cap=market_cap,
        interest_debt=interest_debt,
    )


# ---------------------------------------------------------------------------
# 第三步：DCF（三年显性预测 + 永续终值）
# ---------------------------------------------------------------------------

@dataclass
class DCFResult:
    fair_value_per_share: float   # 每股内在价值（元）
    enterprise_value: float       # 企业价值 EV（元）
    equity_value: float           # 归母股权价值（元）
    minority_interest: float      # 已扣除的少数股东权益（元）
    terminal_value: float         # 终值（未折现，元）
    terminal_value_pct: float     # 终值现值占 EV 的比例
    schedule: pd.DataFrame        # 逐年预测明细
    warnings: list                # 触发的预警


def dcf(base_fcf: float, discount: float, g1_3: float,
        g_terminal: float, net_debt_: float, shares: float,
        minority_interest_: float = 0.0) -> DCFResult:
    """三年显性预测 + 永续的 FCFF 折现模型。

    显性预测期只做 3 年，增长率 g1_3——别说预测十年后了，预测三年后
    已经很了不起了。更远的年份与其编造一条精确的十年增长路径
    （旧版的两阶段 g1_5/g6_10 正是这种虚假精确），不如诚实地交给终值：
    3 年后进入永续，增长率 g_terminal（通常取 0%-2%，不应超过名义 GDP，
    否则等于假设这家公司最终比整个经济体还大）。

    终值用 Gordon 模型：TV = FCF4 / (r - g)，再折现回今天。
    代价是终值占 EV 的比例天然更高（80%-90% 是短显性期模型的常态）——
    估值几乎完全由「永续增长」这一个假设决定，这正是它「看似精确、
    实则敏感」的根源（见 README「终值」一节）。

    股权价值 = EV - 净债务 - 少数股东权益：FCFF 是合并口径，属于全体
    资本提供者，少数股东那一份（子公司里不属于上市公司的权益）必须
    剔除，剩下的才是归母股东的价值。
    """
    if discount <= g_terminal:
        raise ValueError(f"折现率({discount:.2%})必须大于永续增长率({g_terminal:.2%})，"
                         "否则终值公式发散，公司会被估成无穷大")
    if shares <= 0:
        raise ValueError("总股本必须为正")

    rows = []
    pv_sum, fcf_t = 0.0, base_fcf
    for t in range(1, 4):
        fcf_t *= (1 + g1_3)
        pv = fcf_t / (1 + discount) ** t
        pv_sum += pv
        rows.append({"年份": f"第{t}年", "增长率": g1_3, "FCF(亿)": fcf_t / 1e8,
                     "折现因子": 1 / (1 + discount) ** t, "现值(亿)": pv / 1e8})

    fcf_4 = fcf_t * (1 + g_terminal)
    tv = fcf_4 / (discount - g_terminal)
    pv_tv = tv / (1 + discount) ** 3
    ev = pv_sum + pv_tv
    equity = ev - net_debt_ - minority_interest_

    schedule = pd.DataFrame(rows)
    schedule.loc[len(schedule)] = {"年份": "终值", "增长率": g_terminal,
                                   "FCF(亿)": np.nan, "折现因子": 1 / (1 + discount) ** 3,
                                   "现值(亿)": pv_tv / 1e8}
    warnings = []
    tv_pct = pv_tv / ev if ev > 0 else 0.0
    if tv_pct > 0.85:
        warnings.append(f"终值占估值 {tv_pct:.0%}，超过 85%：结果几乎完全由"
                        "「永续增长」这一个假设决定，请重点审视 g_terminal")
    return DCFResult(
        fair_value_per_share=equity / shares,
        enterprise_value=ev,
        equity_value=equity,
        minority_interest=minority_interest_,
        terminal_value=tv,
        terminal_value_pct=tv_pct,
        schedule=schedule,
        warnings=warnings,
    )


# ---------------------------------------------------------------------------
# 敏感性分析与反向 DCF
# ---------------------------------------------------------------------------

def sensitivity_matrix(base_fcf, g1_3, net_debt_, shares,
                       r_center: float, g_center: float,
                       r_steps=(-0.02, -0.01, -0.005, 0.005, 0.01, 0.02),
                       g_steps=(-0.01, -0.005, 0.0, 0.005, 0.01),
                       minority_interest_: float = 0.0) -> pd.DataFrame:
    """折现率 × 永续增长率的每股估值矩阵。

    DCF 给出的单点数字并不重要，重要的是这个矩阵体现的区间——
    两个最敏感参数各挪 1%，估值可能变动 30%+。看区间做决策，
    而不是对着小数点后两位的自我安慰。
    """
    mat = {}
    for dr in r_steps:
        r = r_center + dr
        if r <= g_center + min(g_steps) + 0.001:
            continue
        row = {}
        for dg in g_steps:
            g = g_center + dg
            if g >= r:
                row[f"g={g:.1%}"] = np.nan
                continue
            res = dcf(base_fcf, r, g1_3, g, net_debt_, shares, minority_interest_)
            row[f"g={g:.1%}"] = res.fair_value_per_share
        mat[f"r={r:.1%}"] = row
    return pd.DataFrame(mat).T


def reverse_dcf(price: float, base_fcf: float, discount: float,
                g_terminal: float, net_debt_: float, shares: float,
                minority_interest_: float = 0.0) -> float:
    """反向 DCF：解出「当前股价隐含的未来三年平均增长率」。

    正向 DCF 问「我假设增长 X%，值多少钱」；反向 DCF 问
    「市场今天这个价，等于在赌它未来三年平均每年增长多少」。
    把模糊的「贵不贵」翻译成一个可以用行业研究回答的具体问题——
    这才是 DCF 最重要的用法。

    实现：二分法求解使每股内在价值 = 现价的 g1_3（显性期增长率）。
    """
    def gap(g: float) -> float:
        return dcf(base_fcf, discount, g, g_terminal,
                   net_debt_, shares, minority_interest_).fair_value_per_share - price

    lo, hi = -0.30, 0.50  # 现实中的长期增长不会超出 [-30%, +50%]
    if gap(lo) > 0 or gap(hi) < 0:
        return float("nan")  # 现价在合理增长区间之外（极度低估或高估）
    for _ in range(80):
        mid = (lo + hi) / 2
        if gap(mid) > 0:
            hi = mid
        else:
            lo = mid
    return (lo + hi) / 2
```

## 结合其他方法

没有任何一种估值方法是完美的。多种方法交叉验证是成熟投资者的标志：

方法|	擅长|	不擅长
-|-|-
DCF	|绝对价值、长期判断|	短期定价、高波动公司
PE/PB|	快速比较、行业对标|	周期公司（PE 失真）
PEG	|成长性定价|	亏损公司
EV/EBITDA|	跨公司比较（去除资本结构影响）|	重金融公司
