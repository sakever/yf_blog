架构设计回答的是系统由哪些组件/边界组成、它们如何交互、技术选型、部署形态、质量属性怎么满足（性能、可用性、安全、可观测性、成本等）。架构模式是架构设计里的常用构件，比如分层架构、事件驱动、微服务、CQRS、六边形架构

设计模式回答的是在某个局部，对象/模块之间如何组织，才能让代码更可复用、可扩展、可维护。它通常是代码级或模块级的解决方案
